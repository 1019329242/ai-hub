# AI Hub · AI 导航

一个**单文件、零依赖**的 AI 工具导航页，把各领域的 AI 官网一网打尽。

- 在线地址：https://github.com/1019329242/ai-hub
- 直接双击 `ai-hub.html` 用浏览器打开即可使用，**无需任何安装、构建或联网**。

## 特性

- 🗂️ **分类导航**：按领域汇总各类 AI 官网入口，一页直达。
- 🎨 **深色主题**：护眼的暗色 UI，自适应宽度，手机/桌面都能看。
- 🎮 **彩蛋小游戏**：页面内置一个轻量 canvas 小游戏，点一下就能玩。
- 📦 **纯静态单文件**：全部样式与脚本内联在 `ai-hub.html` 中，方便拷贝、分享与部署。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `ai-hub.html` | 导航页本体（HTML + 内联 CSS/JS，单文件即可运行） |
| `ai-hub截图.png` | 页面效果截图 |

## 本地使用

```bash
# 方式一：直接打开
双击 ai-hub.html

# 方式二：本地起个静态服务（可选）
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/ai-hub.html
```

## 部署

因为是纯静态文件，可直接：

- 推到 GitHub 后开启 **GitHub Pages**；
- 或丢到任意静态托管（Vercel / Netlify / 对象存储）即可上线。

> 本项目为个人 AI 工具收藏导航，链接如有失效欢迎自行更新 `ai-hub.html` 中的地址。
